# action0-pipeline

Composable, fully typed processing pipelines for Python.

```shell
uv add action0-pipeline    # not on PyPI yet — install from GitHub for now
```

The project is in its scaffolding stage: the layout, tooling and CI are in
place, the modules are not written yet. Fully typed (checked with mypy
strict, pyright and ty), Python 3.11+, no runtime dependencies.

The `action0` namespace is simply the one the author likes to use for
personal projects.
